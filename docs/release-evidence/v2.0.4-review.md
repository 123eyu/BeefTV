人工阅读的高风险代码（不是全部 9100 行逐行读）：

- `web/src/components/canvas/canvas-lod-layer.tsx`、`web/src/lib/canvas/canvas-lod-thumbnails.ts`（#250）：远景用一张 canvas 画缩略图，交互节点仍保留 DOM 卡片；缩略图有 LRU 上限 900 条、并发 4、失败 1 秒后可重试，切换账号清空；未发现节点漏画或事件丢失的路径。
- `backend/internal/operations/media_image.go`、`media.go`（#252）：`imageCrop` 在打开资源前先校验（`valid()` + 只允许 `media.inspect` + `frames` 模式 + 图片 MIME），越界与非法裁剪在打开资源前就被拒绝；概览才允许缩小，检查始终保留原始像素。
- `backend/internal/operations/generation_submit.go`、`ops.go`（#255/#261）：内置助手提交仍要求已确认的授权回合（`TurnID`），外部 MCP/CLI 走独立入口并强制 `expectedRevision`、`expectedModelConfigRevision` 和稳定 `operationId`，提议本身不生成也不扣费。
- `agent-host/durable-session-owner.mjs`、`studio-digest.mjs`（#247/#261）：画布读失败时不把历史快照当作当前现场，只有新一轮真实读取才解除冲突闸门。
- `backend/internal/generation/seedance.go`、`web/src/lib/model-capabilities.ts`（#262）：时长下限 2 秒/4 秒与提示文案一起改，测试同步更新。
